# Potap — Godot 4.7.2

Откройте `project.godot` в Godot 4.7.2 и нажмите **F5** для запуска проекта. Если проект был открыт до обновления, закройте
и снова откройте его, чтобы редактор перечитал сцены и настройки.

Управление:

- **Пробел** — начать игру и прыгать; удерживайте для более высокого прыжка.
- **← / →** или **A / D** — движение.
- **↓** или **S** — вставить собранный ключ в замок или открыть блок под героем.
- **Shift / Ctrl / Alt** — дополнительные клавиши прыжка.

Игра рисуется в исходном разрешении 256 × 256. Размер окна при запуске —
768 × 768; целочисленное масштабирование и фильтр Nearest сохраняют чёткие пиксели.

Изменения для Godot 4:

- GDScript обновлён на `@onready`, `Callable`, `PackedVector2Array` и текущие API строк/цветов.
- Сцены переведены на `AnimatedSprite2D`, `TileMapLayer` и `TileSetAtlasSource` с тайлами 8 × 8.
- Координаты игровой сетки используют `Vector2i`; управление настроено через Input Map.
- Звуковой генератор запускается до получения playback, использует потоковое воспроизведение
  и округляет длительности нот до целого числа отсчётов.
- Исправлен индекс заключительного кадра спрайта: 6 вместо отсутствующего 7.
- Устаревшие параметры окна, рендерера, Environment и HTML5-экспорта заменены параметрами Godot 4.

Автоматическая проверка из этой папки (замените `godot` путём к исполняемому файлу):

```sh
godot --headless --path . --editor --import
godot --headless --path . --script res://tests/smoke_test.gd
```

Проверка охватывает старт, управление, движение, прыжки, сбор предметов, замки,
выходы, смерть, преследователя по таймеру, победу и генерацию звука, а также
по 180 игровых шагов со случайным управлением на каждом из 15 уровней.
Она не является полным ручным прохождением всех уровней. При успехе выводится `PASS`.

Для браузерной сборки используйте пресет **Web** и экспортные шаблоны Godot 4.7.2:

```sh
mkdir -p exports/html5
godot --headless --path . --export-debug Web
```

Файл `exports/html5/potap.html` нужно открывать через HTTP-сервер.
Пресет использует один поток и не требует заголовков для SharedArrayBuffer.

Справка: [миграция Godot 3 → 4](https://docs.godotengine.org/en/stable/tutorials/migrating/upgrading_to_godot_4.html),
[звуковой генератор](https://docs.godotengine.org/en/stable/classes/class_audiostreamgenerator.html).

## Окно игры

При запуске игра открывается по центру экрана в окне 768 × 768.
В нижней части игрового поля есть подписанные кнопки:

- **Окно** — оконный режим (также F10);
- **Весь экран** — полноэкранный режим (также F11);
- **Выход** — завершение игры;
- **Пауза / Продолжить** — останавливает и возобновляет игру;
- **Музыка: ВКЛ / ВЫКЛ** — включает и отключает весь игровой звук
  (в текущей версии он состоит из синтезируемых звуковых эффектов).

Клавиатура:
- **Enter** (в том числе цифровой блок) — переключает окно / полный экран;
- **Esc** — выход из игры;
- **P** — пауза / продолжение;
- **M** — звук включён / выключен.

Пауза приостанавливает игровой таймер, врагов, анимации и звуки.
Панель остаётся активной, поэтому снять игру с паузы можно клавишей P
или кнопкой «Продолжить».

**Важно для запуска через F5:** Godot 4.7 по умолчанию может запускать
игру внутри редактора (режим `Embed Game`). В таком режиме переключение
между окном и полноэкранным режимом не поддерживается. На вкладке
**Game** откройте меню справа сверху и отключите **Embed Game on Next Play**,
затем запустите игру заново. При нажатии кнопок в режиме Embed Game
игра покажет подсказку вместо молчаливого отказа.

Кнопки панели нажимаются мышью и **не получают клавиатурный фокус**:
стрелки перемещают персонажа, а пробел запускает игру и отвечает за прыжок,
поэтому эти клавиши не должны случайно нажимать кнопку «Выход».
В браузере после нажатия на кнопку панели фокус возвращается игровому полю.
Кнопки настольного приложения не показываются в веб-версии: в браузере
управление расположено **под игровым полем**, не закрывая его.
В браузере кнопка «Выход» завершает Godot, но вкладка остаётся
открытой из-за ограничений браузера. В браузерной версии клавиши Enter, P, M
обрабатываются HTML-интерфейсом; Esc также завершает игру, если браузер
передаёт это нажатие странице. В полноэкранном режиме некоторые браузеры
перехватывают Esc для выхода из самого полноэкранного режима.
Кнопка «Выход» остаётся доступной в любом случае.

В готовой Web-сборке из папки `docs/` пауза приостанавливает игровой цикл
Emscripten, а музыка/звуки переключаются через Web Audio API. В настольной
версии пауза использует `SceneTree.paused`, а звук — шину `Master`.

Если браузер запрещает полноэкранный режим, например при запуске игры
внутри iframe без разрешения fullscreen, под кнопками появится сообщение.
Откройте игру отдельной вкладкой и нажмите «На весь экран» снова. Кнопки
режимов всегда доступны, чтобы можно было повторить попытку.

В веб-экспорте `docs/index.html` и `docs/potap.html` используется
`canvasResizePolicy: 0`, а масштабирование и центрирование выполняют
`docs/potap-ui.js` и `docs/potap-ui.css`. При повторном экспорте из Godot
нужно сохранить эту HTML-обвязку и подключение файлов интерфейса.

## Справка по клавишам и сохранения

В игре появился экран **Клавиши (H)** с подсказкой по управлению. Он
доступен во время партии и с титульного экрана. Пока справка открыта,
игра стоит на паузе и продолжится после закрытия подсказки.

| Клавиша | Действие |
| --- | --- |
| **← / →**, **A / D** | движение |
| **↓ / S** | использовать ключ или открыть блок |
| **Space**, **Shift / Ctrl / Alt** | прыжок; Space на стартовом экране — новая игра |
| **Enter** | полноэкранный / оконный режим |
| **Esc** | выйти из игры |
| **P** | пауза / продолжить |
| **M** | включить / выключить звук |
| **F5** | сохранить текущую партию |
| **F9** | загрузить партию |
| **C** | продолжить сохранённую игру на стартовом экране |
| **N** | новая игра на стартовом экране |
| **H** | показать / скрыть справку |

Сохранение выполняется **вручную** через кнопку «Сохр. F5» или клавишу
F5 во время активного уровня; оно работает и на паузе. В файл записывается
полное состояние уровня: номер, очки, жизни, таймер, персонаж, враги,
ключи, собранные предметы, уже изменённые блоки, анимации и состояние
генератора случайных чисел. Временные звуковые очереди не сохраняются.

При следующем запуске на титульном экране можно выбрать
**«Продолжить (C)»** или **«Новая игра (Space)»**. Новая игра **не удаляет**
прежнее сохранение; оно заменяется только при следующем сохранении.
«Загрузить (F9)» доступно и во время текущей партии.
Повреждённое или несовместимое сохранение игнорируется: игра
не заменяет им текущий прогресс.

Файл сохраняется по пути `user://potap-save.json` (папка данных
пользователя Godot). В браузерном Web-экспорте пользовательские файлы
обычно хранятся в хранилище браузера для конкретного адреса сайта.
Если удалить данные сайта или использовать приватный режим, сохранение
может не пережить следующий запуск.

**Важно про уже опубликованную браузерную сборку:** файлы
`docs/potap.pck` и `docs/potap.wasm` пока содержат старый экспорт игры.
Внешняя HTML-панель уже умеет показывать справку и кнопки, но
**«Сохранить», «Загрузить», «Продолжить» и «Новая игра» не будут
активны**, пока Godot-проект не экспортирован заново с новым
`main.gd`. Чтобы опубликованная страница заработала, экспортируйте
Godot 4.7.2 в Web (с поддержкой JavaScriptBridge), перенесите новые
`.pck` и сопутствующие файлы движка в `docs/` и сохраните изменения
HTML-обвязки `index.html`, `potap.html`, `potap-ui.js`,
`potap-ui.css`. В браузере F5 может перезагружать страницу — надёжнее
пользоваться кнопкой «Сохранить».
